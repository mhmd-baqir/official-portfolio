# معرض مشاريع المطور محمد باقر (Mohammed Baqir Portfolio) 🚀

بورتفوليو احترافي، عصري، فائق السرعة، ومتجاوب بالكامل 100% مع الهواتف الذكية والأجهزة اللوحية واللابتوب، يجمع ويرتب كافة مشاريعك المرفوعة على GitHub في واجهة موحدة مع إمكانية التثبيت المباشر كتطبيق (PWA).

---

## 🌟 الميزات والمواصفات:
1. **تصميم متجاوب ومتطور (Mobile & Laptop First)**: تجربة تصفح سلسة على شاشات الهواتف وأجهزة الكمبيوتر مع تأثيرات زجاجية (Glassmorphism) وألوان مريحة للعين.
2. **تطبيق ويب تقدمي (PWA Ready)**:
   - مزود بملف `manifest.json` و `sw.js` (Service Worker).
   - يمكنك تثبيته على شاشة هاتفك (iPhone أو Android) بضغطة زر ليصبح كأي تطبيق مثبت على الجهاز!
   - يدعم التصفح السريع والعمل حتى عند انقطاع الإنترنت (Offline Mode).
3. **دعم كامل للغتين (العربية والإنجليزية - Bilingual)**:
   - تبديل فوري بين العربية (RTL) والإنجليزية (LTR) مع حفظ الاختيار تلقائياً في المتصفح.
4. **الوضع الليلي والنهاري (Dark / Light Theme)**:
   - تبديل فوري بضغطة زر بين الوضع المظلم الحديث والوضع الفاتح المريح.
5. **محرك بحث وفلاتر ذكية (Live Instant Search & Filter)**:
   - البحث بالاسم، التقنية، أو الكلمات المفتاحية في أجزاء من الثانية.
   - فلاتر تصنيف: Full-Stack & Next.js، PHP & MySQL، Python & AI، Front-End.
6. **نافذة تفاصيل تفاعلية (Interactive Project Modal)**:
   - تفتح تفاصيل كل مشروع، ميزاته، تقنياته، وروابط الكود مباشرة.
7. **زر مشاركة ونسخ الرابط بلمسة واحدة**:
   - لمشاركة الموقع عبر WhatsApp أو وسائل التواصل أو نسخه فوراً.

## 📱 كيف تفتح البورتفوليو وتثبته على هاتفك؟

### أولاً: رفعه إلى GitHub Pages (ليصبح لديك رابط عالمي مجاني مدى الحياة)
المستودع `portfolio` موجود بالفعل على حسابك:
1. افتح موجه الأوامر (Terminal / PowerShell) في هذا المجلد:
   ```bash
   git init
   git add .
   git commit -m "Add modern PWA portfolio for Mohammed Baqir"
   git branch -M main
   git remote add origin https://github.com/mhmd-baqir/portfolio.git
   git push -u origin main --force
   ```
2. ادخل على مستودع `portfolio` في GitHub:
   - اذهب إلى **Settings** > **Pages**
   - تحت **Build and deployment**، اختر الفرع **`main`** ثم اضغط **Save**.
3. خلال دقيقة واحدة، سيصبح موقعك متاحاً على الرابط:
   👉 **`https://mhmd-baqir.github.io/portfolio/`**

---

### ثانياً: تثبيته على شاشة الهاتف كتطبيق (بدون متجر وبدون تعقيد)

#### على هواتف Android (Chrome):
1. افتح رابط موقعك في متصفح Google Chrome على الهاتف.
2. اضغط على علامة الثلاث نقاط (⋮) في أعلى زاوية المتصفح.
3. اضغط على **"إضافة إلى الشاشة الرئيسية" (Add to Home screen)** أو **"تثبيت التطبيق" (Install app)**.
4. ستظهر أيقونة باسم "مشاريع محمد" على شاشة هاتفك مثل أي تطبيق مستقل!

#### على هواتف iPhone (Safari):
1. افتح رابط موقعك في متصفح Safari على الآيفون.
2. اضغط على زر المشاركة (أيقونة المربع وفيها سهم للأعلى ⬆️) أسفل الشاشة.
3. مرر للأسفل واضغط على **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)** ثم اضغط **"إضافة" (Add)**.
4. سيتم تثبيته فوراً على شاشتك الرئيسية وتفتحه بلمسة واحدة في أي لحظة.
